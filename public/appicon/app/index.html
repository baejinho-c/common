자주 묻는 질문

AppIcon AI는 어떤 App icon generator 인가요?+

AppIcon AI는 짧은 앱 설명이나 app icon prompt만 입력하면 AI가 Apple Style, Material, Glass 등 스타일 규칙을 적용해 App Store·Play Store에 제출 가능한 1024 app icon을 생성하는 AI app icon maker입니다.

iOS icon과 Android icon 규격을 지원하나요?+

네. iOS icon은 1024×1024 정사각형, Android icon은 adaptive safe zone을 고려한 구도로 생성합니다. Web, macOS, Windows 플랫폼 프리셋도 선택할 수 있습니다.

앱 아이콘 만들기를 처음 해도 되나요?+

디자인 경험이 없어도 됩니다. 'AI 채팅앱', '파스텔 메모앱'처럼 한국어로 적어도 Prompt Builder가 app icon prompt를 영문 전문 프롬프트로 확장합니다. 앱 아이콘 AI가 구도·명암·색감까지 자동 보정합니다.

무료 체험과 크레딧은 어떻게 되나요?+

회원·비회원 모두 하루 3회 무료로 아이콘 생성 AI를 이용할 수 있습니다. 회원가입 시 추가로 10회 크레딧이 지급되며, 무료 한도 소진 후 생성 1회당 1크레딧이 차감됩니다.

기존 App icon maker와 무엇이 다른가요?+

단순 템플릿 합성이 아니라 GPT 기반 app icon prompt 확장 + DALL·E 이미지 생성 + 플랫폼별 디자인 규칙 엔진을 결합합니다. 경쟁 앱 분위기 참고, 카테고리별 키워드 매칭으로 아이콘 생성 AI 품질을 높입니다.
